# 支架冷启动发车

MCU 复位或上电后默认使用原有普通启动，满足连续 500 ms 的稳定姿态条件后开始平衡。
通过 `coldstart start` 或小程序「冷发车」按钮手动发车。支架应使最低腿高时车轮离地，并允许双腿
伸长到 69.5 mm 后车轮接触地面、车身向前离开支架。当前没有触地或舵机位置传感器，
流程按腿高指令和编码器行程运行。

## 手动冷发车流程

| 阶段 | 行为 | 默认时长/条件 |
| --- | --- | --- |
| waiting | 双腿等高 44.5 mm、轮输出为零、关闭横滚/腿高自适应 | 原始俯仰 ≤20°、横滚 ≤10°、合角速度 ≤20°/s，速度/转向请求绝对值 <1，连续稳定 500 ms |
| raising | 双腿按平滑曲线同步从 44.5 升至 69.5 mm，轮输出仍为零 | 3 s |
| settling | 双腿保持 69.5 mm，给舵机留出稳定时间 | 500 ms |
| ramping | 运行原串级 PID；输出权限、积分累积权重和电机死区从 0 平滑升至 100%，速度目标从 0 升至前进 30 RPM | 1 s |
| driving | 双腿保持 69.5 mm，关闭横滚补偿、转向目标为零，全量平衡 PID，前进目标 30 RPM | 从 ramping 起累计有符号平均轮行程达到 120 mm |
| handover | 保持平衡输出连续，恢复当前正常目标；速度用 300 ms 过渡，腿高及横滚补偿用 1.5 s 渐变恢复 | 1.5 s |
| complete | 原有正常控制流程，保持已学到的 PID/IMU 状态 | 再次发车需显式命令 |

这里的腿高上下限为 44.5/78.5 mm，中位为 61.5 mm，冷发车目标在中位基础上增加 8 mm，
即 69.5 mm。手动冷发车先使用最低腿高，即使 Flash 保存的是其他高度，也先执行上述等高流程；结束时恢复当时参数快照
中的腿高和横滚目标。发车临时值不写入共享参数或 Flash。
普通上电继续使用已保存的正常腿高，不执行上述升腿和前进流程。

启动等待使用原始车身姿态，避免支架固定的姿态不在普通平衡点 ±8° 内而无法发车。
进入发车后保留 30° 倾倒限制，平衡阶段还检查带腿高补偿的俯仰误差。
正常 `control on` 仍使用原来的 500 ms 门控。

## 距离与调节

实车轮胎外径已确认是 44 mm。左右编码器各为 7 线 × 4 边沿 × 50 减速比，
即每轮一圈 1400 计数，120 mm 约对应每轮 1216 计数。

遥控器和小程序的前进对应固件负转速，因此发车目标为 **−30 RPM**；距离沿这个
前进方向累计，负编码器转速增加行程，正转速扣减行程。

实现复用每 50 ms 的编码器读取：`getRPM()` 的固定 50 ms 换算乘回
`50/60000` 得到实际增量圈数，再乘 `π × 44 mm`。两轮取带符号平均；
倒退会扣减行程，左右反向的原地转动不会累计。升腿期间、平衡输出刚开始的第一个
跨阶段读取区间不计入发车行程。调度延迟不会通过“目标速度 × 时间”伪造行程。

达到约 12 cm 时开始恢复正常目标，减速期间仍有实际滑行距离，最终位移需实车确认。
车轮悬空空转、打滑或单侧空转时，编码器无法判断实际车身位移。

所有发车常量集中在 `Component/UserApp/CtrlAlgorithm/ColdStartLaunch.hpp`：
腿高曲线、升腿/稳定/输出渐增时长、30 RPM、120 mm、44 mm 轮径和超时。
现有 PID 增益、重心标定、左右舵机映射与 Flash 格式不变。

## 中断和诊断

- `control off`、安装模式、独占 Flash 维护取消本次冷启动。再次 `control on`
  只走普通平衡门控；重新上电、复位也不会自动发车，需显式 `coldstart start`。
- 发车过程 IMU 无效、超出倾倒范围或采样中断超过 50 ms，立即取消并关闭输出。
  连续三次 IMU 失败仍会进入已有的运行故障锁存。
- 从输出渐增开始，6 s 内行程未达到 120 mm，则关闭控制和执行器输出。
  电机/编码器未连接时应观察到该超时，不会按时间假定发车成功。
- 普通追加 `save` 不打断发车；独占 `save recycle` 继续受原保存互锁保护。
- 发车期的 30 RPM 是本地临时目标，不刷新遥控看门狗；切回正常时使用仍有效的
  遥控请求，超时的速度/转向/横滚目标仍为零。

发送 `@controlstate\n` 可查看阶段、行程和输出比例，例如：

```text
coldstart=driving abort=0 travel=83.0mm gain=1.000
```

原因码：0 无错误，1 外部中断，2 姿态超限，3 IMU 无效，4 行程超时，
5 采样间隔过长，6 编码器数据无效。`gain` 为当前使用的输出比例；
发车取消后普通控制再次解锁时可以恢复为 1，但阶段仍记录 `aborted`。

## 手动发车与自适应腿高

| 命令 | 行为 |
| --- | --- |
| `coldstart start` | 重新执行完整支架发车并开启控制；清除旧速度/转向/横滚请求。重复发送不重置正在进行的行程 |
| `coldstart stop` | 立即停止发车、关闭车端控制和执行器输出；安装模式下保留安装舵机保持 |
| `coldstart status` / `coldstart` | 查询阶段、是否进行中、中断原因、行程、输出比例和车端控制状态 |
| `autoleg on` / `autoleg off` | 开启/关闭横滚自适应腿高；关闭时两腿使用共同高度，开启时约 500 ms 渐进恢复 |
| `autoleg status` / `autoleg` | 查询开关意愿 `enabled` 与当前实际调节状态 `active` |

已处于正常平衡输出时，重新发车会回复 `control-off-required`；放稳在支架上，
先关闭车端控制再发车。安装模式、启动未就绪或存储操作进行中会拒绝发车。
停止命令会清除尚未被运动任务消费的发车请求，避免紧接着开控时意外发车。

自适应腿高默认开启，开关仅本次上电有效，不写入 Flash。冷启动的升腿和驶离阶段
始终保持两腿等高，结束后按这个开关恢复；`enabled=1 active=0` 表示选择开启，
但当前冷启动、未解锁、停控或安装状态尚未运行调节。普通腿高目标仍可调整。

```text
coldstart: phase=driving active=1 abort=0 travel=83.0 gain=1.000 control=on
autoleg: enabled=1 active=0
```

小程序遥控页下方有「冷发车 / 停止发车」和「自适应腿高」switch；连接后读取
真实状态，发车时周期刷新。开关等待车端回执确认，回执缺失显示状态未确认。
发车期间锁住本地摇杆，完成后可手动启用。页面停止按钮也会取消正在进行的发车。

## 自动验证

`cold_start_launch_test` 验证时序、连续稳定条件、等高曲线、输出比例、轮径换算、
有符号行程、超时及取消不重试。`cold_start_task_test` 使用实际运动任务验证
默认普通启动（含姿态不满足时持续等待）、手动发车至 69.5 mm、PID/死区渐增、
横滚恢复、无输出断档、停控抢占、安装模式、IMU 故障和倾倒。
`runtime_tuning_test` 使用生产默认启动设置，验证实际命令触发发车、停止及重新发车。

电机与舵机断线情况下的主机及板上测试不能证明带负载发车稳定，升腿速度、
输出渐增时长和支架接触位置仍需在相同机械配置下确认。

## 2026-09-20 实板验证

以下为最初自动发车至 61.5 mm 版本的历史板上记录；当前默认普通启动、手动发车
至 69.5 mm 的修改尚未进行实板验证。2026-09-21 新增命令、小程序界面以及前进符号
修正后，Debug/Release 各 52 项主机测试、三种固件构建和镜像校验通过；ST-Link
当前未连接，按用户要求保留新版固件，**本次命令版本尚未烧录或进行实板验证**。

设备为 STM32F411（512 KiB Flash），电机线与舵机线均断开。使用现有
`STlink_hla.cfg` 连接 ST-Link；尽管探头报告低目标电压，烧录、读回和调试均完成。

| 检查 | 结果 |
| --- | --- |
| 自然启动、无编码器计数 | 实际 IMU 采样下依次进入同步升腿、稳定、输出渐增和 30 RPM 目标阶段；两腿目标保持相等，到中位 61.5 mm；约控制任务启动 10 s 后因行程为零超时，轮/舵机四路 PWM 均为零 |
| PWM 渐增 | 采样到输出比例 0、0.11378、0.38102、0.71825、0.94669、1；两路实际 TIM1 比较寄存器与 PID PWM 幅值一致 |
| 距离阈值 | 通过 SWD 向 TIM2/TIM3 计数器注入增量，每轮 1215 个计数仍在 driving；每轮 1216 个计数时行程约 120.0627 mm，进入 handover |
| 连续交接 | handover 期间反复检查 `armed` 保持为真，结束后 complete、速度目标恢复 0；无额外 500 ms 解锁等待 |
| 命令与安装打断 | 通过 SWD 将命令送入现有 UART 接收队列，由真实命令任务处理；安装模式打断升腿并恢复 44.5 mm，退出后启控不重复发车；完成发车后 off/on 也不重复 |
| 最终状态 | `control off`，安装模式关闭，轮电机与舵机 PWM 均为零；下次复位或上电重新执行冷启动 |
