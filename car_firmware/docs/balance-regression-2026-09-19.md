# ba5b8e7 后平衡过冲与振荡的回归排查

## 现象与结论范围

用户报告在 `ba5b8e779502d7159da676ae37dfb85a20f972c0` 后，执行 `control on`
时车身围绕平衡点前后摆动、轮子反复纠正。原保存参数 7.4° / Kp 75.35 时已有此现象，
之后曾调整参数。此次板上备份实际读到偏置 9.5° / Kp 基准 65.35。

代码对比确认该提交改变了 IMU 反馈时序和停控后的融合恢复方式。实板已复现
`control on` 丢弃已学到零偏的行为，并验证修正后保留估计、停控时继续跟踪。
恢复此前的传感器时序是针对反馈延迟的修正候选；本次电机、舵机均断开，
**尚不能据无负载测试认定带负载振荡已经消失，也不能断言所有原因已排除。**

## 提交对比

| 项目 | ba5b8e7 之前 | ba5b8e7 |
| --- | --- | --- |
| DLPF_CFG | 0 | 100 Hz 配置下选择 3 |
| SMPLRT_DIV | 9 | 9 |
| 传感器寄存器更新率 | 800 Hz | 100 Hz |
| 运动任务 / VQF 调用周期 | 10 ms | 10 ms |
| 陀螺硬件滤波延迟 | 0.98 ms | 4.8 ms |
| 加速度硬件滤波延迟 | 0 ms | 4.9 ms |
| 普通 control off | 暂停采样 | 暂停采样 |
| 暂停后 control on | 沿用之前融合状态 | resetFusion，清空姿态、零偏、滤波器状态 |
| G1000 换算系数 | 30.768（旧代码笔误） | 32.8（按手册修正） |
| 固定角速度偏置 | 加上 `(2.5, 0.7, 0.9)` °/s | 移除，使用 VQF 在线估计 |

硬件更新率由 `gyro_base / (SMPLRT_DIV + 1)` 得到；DLPF=0 的基频为 8 kHz，
DLPF=3 为 1 kHz。滤波延迟和更新率依据
[TDK MPU-6000/6050 寄存器手册 §4.2–4.3](https://invensense.tdk.com/wp-content/uploads/2015/02/MPU-6000-Register-Map.pdf)。
这些是传感器配置与手册值，并非对整车端到端延迟的实测。

角度 PID 的 D 项使用相邻姿态测量差分，而不是直接使用原始角速度。
因此，即使 P/I/D 数字不变，改变姿态反馈延迟也会改变闭环响应。
100 Hz 主控读取同为 100 Hz 的独立传感器输出，还会受两者采样相位影响。
这是反馈延迟的明确变化，但它对本车稳定裕度的具体影响需要带负载 A/B 验证。

VQF 的 `resetState()` 会清空 `state.bias`、姿态四元数、滤波历史和静止检测。
500 ms 的平衡启动门控不等于零偏已经重新收敛。VQF 静止检测默认时间门槛为
1.5 s，具体估计参数说明见 [VQF 参数文档](https://vqf.readthedocs.io/en/stable/ref_cpp_params.html)。

## 本轮修正

- MPU6050 恢复 DLPF=0、SMPLRT_DIV=9 的原有寄存器组合；800 Hz 更新寄存器，
  100 Hz 读取并更新 VQF，积分周期仍为 0.01 s。
- 系统 ready 时，普通 `control off` 继续采样、姿态融合和零偏估计，轮输出保持为零。
  再次 `control on` 保留融合状态，同时仍重新满足 500 ms 稳定门控。
- 安装模式、非 ready 状态和独占 Flash 维护仍可暂停采样；相应恢复路径仍重新初始化融合。
- 保留正确的量程换算、PLL 时钟、14 字节一致读取、寄存器回读和 I/O 故障处理。
- 未修改任何 PID 默认值或已保存运动参数；未恢复固定板级角速度偏置。

## 验证

新增检查先在修正前失败，再在修正后通过：

1. 默认传感器寄存器配置恢复为 DLPF=0 / divider=9。
2. 在普通 control off 的 2 秒期间，真实运动任务持续消费 IMU 样本并更新姿态。
3. control on 不调用融合重置，仍等待完整启动门控；再次关闭后保持零输出。

Debug、Release 各 50 项 CTest 全部通过，VQF 禁止 `-Ofast` 的检查通过。
Release、RelWithDebInfo 构建通过，二者 update BIN 完全一致，镜像地址和 CRC 检查通过。
安装模式、持续 IMU 失败锁存、保存互锁、control off/on 等既有回归继续通过。

使用 ST-Link / HLA，通过正常命令队列执行相同的停控/启控流程：

| 实板观测 | 修正前 | 修正后 |
| --- | --- | --- |
| control off 期间完整 VQF 状态 | 2.5 s 前后逐字节相同，估计器停止 | 前后不同，持续更新 |
| Y 轴零偏，开启前 → 开启约 400 ms 后 | 约 −0.421°/s → +0.072°/s | 约 −0.429°/s → −0.429°/s |
| Z 轴零偏，开启前 → 开启约 400 ms 后 | 约 +3.39°/s → +0.46°/s | 约 +3.39°/s → +3.39°/s |
| VQF 积分周期 | 0.01 s | 0.01 s |

零偏数据证明停控/启控的融合行为差异，并不单独证明车身振荡的全部因果关系。
`restT` 是静止检测时间，会被移动或噪声重置，不能用它代替 IMU 采样计数。

## 后续实车确认

使用当前候选版和相同的一组保存参数进行比较，先 control off 静置让估计稳定，再开启控制，
观察同样扰动下过冲和振荡是否减小。此次没有验证原父提交的完整带负载 A/B，
也没有验证电机振动条件下恢复宽带传感器配置的噪声影响。
若仍有明显振荡，需要记录姿态、轮速和 PWM，进一步区分角度环阻尼、速度环积分
及机械因素；不应把本次无负载测试当作带负载调参完成。
